# 23 · 法线贴图与切线空间 TBN

> 对应 App 第 23 项 · 难度：光照与材质

## 你将搞懂

- 法线贴图的存储格式与作用
- 切线空间 TBN 的定义与构建
- 扰动强度控制
- 手性/镜像与 mikktspace

## 先讲人话

法线贴图把高频几何细节（砖缝、凹凸）"烘焙"成**逐纹素的法线**，低面数网格获得高细节光照——不用加一个三角形。

存储格式：`RGB = 法线方向 × 0.5 + 0.5`。默认值 `(128, 128, 255)` = 未扰动的 +Z（紫蓝色）。

## 切线空间

每个顶点建一个局部坐标系：

```text
N = 法线（表面朝外）
T = 切线（贴图 u 增长的方向）
B = 副切线（贴图 v 增长的方向，= cross(N, T)）
```

法线贴图里的法线定义在**切线空间**。两种光照方式：

1. 把 L/V 变换进切线空间做点积（VS 构建好 TBN，FS 变换光照向量）；
2. 把采样法线乘 TBN 变换到世界空间（本 App 做法，光源可自由移动）。

## 核心代码

**顶点着色器**：构建 TBN 矩阵（平面墙的切线是固定值；通用模型由导出工具提供切线属性）

```glsl
vec3 N = normalize(mat3(u_model) * a_normal);
vec3 T = normalize(mat3(u_model) * vec3(1.0, 0.0, 0.0));  // 平面墙：T 沿 X
vec3 B = cross(N, T);
out mat3 v_tbn;                 // mat3 也能作为 varying 传递！
v_tbn = mat3(T, B, N);
```

**片元着色器**：采样法线图、按强度扰动、变换到世界空间、正常 Phong

```glsl
vec3 sampled = texture(u_normalMap, v_uv).rgb * 2.0 - 1.0;  // 解码 0..1 → -1..1
sampled.xy *= u_normalStrength;                             // 强度滑条：0=无效果
vec3 N = normalize(v_tbn * normalize(sampled));             // 变换到世界空间
// 之后与第 21 章完全相同的 ADS 光照
```

**法线贴图的生成**（App 内程序化）：由砖墙高度场中心差分求梯度：

```java
// 对每个像素：左右/上下各取高度差 → 法线 xy 分量
float hR = heightAt(x + 1.5f, y), hL = heightAt(x - 1.5f, y);
float nx = (hL - hR) * 2.2f, ny = (hU - hD) * 2.2f, nz = 1f;
// 归一化后编码：r=(nx*0.5+0.5)*255 ...
```

## 在 App 里怎么玩（第 23 项）

- 砖墙 + 环绕光源，砖缝在无几何的情况下呈现凹凸明暗；
- **法线强度** 滑条 0→3：0 恢复平坦（等于没贴图），越大凹凸越深；
- **光源距离** 滑条：拉近看光在砖缝里"流动"；
- 对比 diffuse 贴图：几何完全是平面，细节全部来自光照。

## 常见坑

- **忘了解码**：直接用 0~1 的贴图值当法线（全是正方向）→ 光照死板。
- **TBN 未正交化**：UV 有剪切时 T、B 不垂直 → 光照方向偏移，需 Gram-Schmidt 正交化。
- **镜像 UV 手性翻转**：mikktspace 导出时切线 w 分量为 -1 表示翻转 T。
- **法线图开 sRGB**：它是数据纹理不是颜色，必须按线性处理。

3. 为什么法线贴图的光照要借 TBN 矩阵？
