# 最小闭环：先让 win32 程序在这台 Windows 64 位机器上跑起来

## 目标
验证（必要时修复）现有 `win32/` 32 章代码能在这台机器上编译成 `study_gl.exe` 并正常运行出画面。

## 步骤

1. **用已装的 MSVC 编译**：本机无 g++/cmake，但有 VS 2022 BuildTools（cl.exe 14.44，不在 PATH）。通过 `call vcvars64.bat && build.bat` 一条命令链完成编译（不改任何代码，先验证基线）。
   - 若编译报错：逐个修复（代码 9/12 写就，可能有个别 MSVC 兼容性问题），直到编译通过。
2. **实跑验证**：后台启动 `study_gl.exe`（菜单模式 + 直跑某章如 `study_gl.exe 7`），等几秒确认进程存活、控制台 HUD 有输出、无崩溃。
3. **截图核验**：用 PowerShell CopyFromScreen 抓 GL 窗口画面，确认渲染内容正常（不是黑屏/白屏）。
4. **让"一键编译"在本机可用**：给 `build.bat` 加约 15 行——cl 不在 PATH 时自动探测并调用 vcvars64.bat（BuildTools/Community/Professional 三处路径探测）。这样你以后直接双击/执行 build.bat 就能编译。
5. 汇报结果：能否跑、什么环境、怎么跑（菜单选章 / `study_gl.exe 章号`）。
